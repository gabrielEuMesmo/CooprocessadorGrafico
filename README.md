# Coprocessador Grafico
O seguinte Coprocessador Gráfico foi desenvolvido inspirado na arquitetura de consoles de 16 bits, possuindo dois motores gráficos e um rasterizador que trabalham em conjunto. O motor de background, responsável por apresentar uma camada de background na saída de vídeo, com 256 padrões diferentes disponíveis, permitir que cada tile seja alterado individualmente, além do deslocamento de cada camada de tile para as 4 direções; o motor de sprites, que permite a inserção de, no máximo, 32 sprites de 16x16 pixels ao mesmo tempo na tela, com configuração de prioridade entre eles, deslocamento dos sprites pela tela para as 4 direções, espelhamento na horizontal e na vertical e definição de transparência; e o rasterizador de polígonos, que permite a inserção de até 8 polígonos de 3 ou 4 lados na tela, dadas quaisquer 4 coordenadas (x,y) diferentes. 

O coprocessador foi inicialmente criado para ser utilizado na plataforma de desenvolvimento De1-SoC, descrito totalmente na liguagem de descrição de hardware Verilog, utilizando como interpretador o programa Quartus Prime. A saída de vídeo do projeto foi integrada à interface VGA (Video Graphics Array) da placa.
